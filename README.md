# SecretSifter Desktop has moved to OWASP

**This repository no longer hosts the SecretSifter Desktop downloads.** The
desktop app (macOS and Windows) is now published and maintained as part of the
official **OWASP SecretSifter** project. Please get it there.

## Download

- **Latest desktop release (macOS + Windows):**
  [github.com/OWASP/SecretSifter/releases](https://github.com/OWASP/SecretSifter/releases)

Current build (v1.8.3):

- macOS: [SecretSifter-1.8.3.dmg](https://github.com/OWASP/SecretSifter/releases/download/desktop-v1.8.3/SecretSifter-1.8.3.dmg)
- Windows: [SecretSifter-1.8.3.exe](https://github.com/OWASP/SecretSifter/releases/download/desktop-v1.8.3/SecretSifter-1.8.3.exe)

The installers are unsigned; on first launch Windows SmartScreen may warn
(click **More info -> Run anyway**) and macOS Gatekeeper may need **right-click -> Open**.

## Project and source

- OWASP project: [github.com/OWASP/SecretSifter](https://github.com/OWASP/SecretSifter) ([owasp.org/www-project-secretsifter](https://owasp.org/www-project-secretsifter/))
- Desktop source: [OWASP/SecretSifter/tree/main/desktop](https://github.com/OWASP/SecretSifter/tree/main/desktop)

## Why the move

SecretSifter is an OWASP Incubator project. To keep a single canonical home and
avoid maintaining duplicate release channels, all desktop downloads now live on
OWASP/SecretSifter. The previous releases on this repository have been retired so
there is one authoritative place to download and cite.
